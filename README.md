The Nowl In One or Nowl All In One, is a web application that was created with the thought of "how many tools and games can I put into a web app without making it look too wierd, while making it still useful to me and my family."
The app consists of 2 types of features: 
Useful tools
- Shared Calendar with telegram bot notifications
- News headlines with an AI summary and a sort of daily news recap through the telegram bot
- A taskboard, replicating a trello board for task managemnet or even project management
 Games
- what started as a how easy is it to code wordle became a ranked wordle clone for my competitive family
- A ranked riddle game mode with daily riddles
- A trivia quest game where users form teams and work together to defeat weekly bosses with their knowledge or luck

The app is still in development and I will continue to feature dump to limit test my UI and UX capabilities. This is just a fun side project for me to take a break from games and make something fun and hopefully useful for my family and friends.
